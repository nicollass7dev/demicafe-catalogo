# DEMI Cafeteria — Catálogo digital

Catálogo responsivo da DEMI Cafeteria, com busca, filtros, detalhes dos itens e lista de interesse.

## Executar localmente

```bash
node server.mjs
```

Acesse `http://127.0.0.1:4173`.

## Conteúdo

Os dados públicos confirmados estão centralizados em `products.js`. Preços, disponibilidade e WhatsApp permanecem sob consulta porque não foram publicados no perfil informado.

Para ativar links diretos do WhatsApp, preencha `BUSINESS.whatsapp` em `products.js` somente com DDD e número.
